# Cờ Caro online 15x15 – luật chặn 2 đầu

- Chơi online với bạn bè qua link phòng, hoặc 2 người trên 1 máy.
- Đổi luân phiên người đi trước mỗi ván.
- Mỗi lượt 30 giây, hết giờ máy tự đánh 1 nước ngẫu nhiên.
- Chat trong phòng (kèm câu chat nhanh).

Chạy trên máy: `npm install && npm start` rồi mở http://localhost:3000
(Đổi thời gian lượt khi test: `TURN_MS=5000 npm start`)

Deploy Render: Web Service, Build `npm install`, Start `npm start`, gói Free.
